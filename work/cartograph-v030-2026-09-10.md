# Cartograph v0.3.0 delivery

## Scope

Refine the canvas using user feedback on a synthetic stress Atlas and then a
real Atlas. Keep all graph identities, relationships, visibility boundaries,
read-monitor semantics and the self-contained runtime package intact.

## Outcomes

- Delivered volumetric galaxies, original idle rotation, anchored decorative
  pulses, faster singleton framing and coupled zoom-out restoration.
- Delivered one always-visible toolbar search field, accessible paginated
  results and atomic first-activation focus / second-activation Markdown.
- Added version/source-SHA/FPS visibility and a ten-second new-node glow while
  retaining 3.5-second opacity, relationship and deletion effects.
- Source PR 8 merged; stable v0.3.0 published from commit
  `fe6de71e56422bda09dd0a92cf59d683d883e396`.
- Marketplace PR 10 subsequently merged at
  `96f57a6c1502724fc5739798f26aea2ab2ca5060`. Both authoritative and generated
  catalogs publish version 0.3.0 at the released source SHA.
- A scoped global APM exact-ref install completed after isolated rehearsal.
  The global native canvas opened the real autogenesis Atlas with 477 nodes,
  no error and the collector still waiting. No privileged collector was run.

## Closure

Closed on 2026-09-10 after source, catalog and consumer deployment were each
verified. The release-follow-up automation was cleared. The user accepted the
real-Atlas view before requesting release, then required restoration of the
visible search field before publication; that final preference shipped.

The 505-node / 1508-relationship stress baseline remained unchanged. No pinned
dependency on the Atlas package was added: Cartograph reads stores as data.
The earlier capture-pressure reliability concern is separate and was not
claimed resolved by this visual release.
