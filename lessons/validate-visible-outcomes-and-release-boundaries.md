# Test what the user sees, not only the implementation's intent

An extreme depth range can be satisfied by a few halo points while the bulk
remains flat. Measure a central distribution span and inspect an actual side
view. Preserve spiral coherence and group separation at the same time.

A correct camera endpoint does not prove a usable transition. Sample the
entire close-in and restoration trajectories, including a distant singleton,
different frame rates and large accumulated yaw. Shortest-angle movement and
pan/zoom coupling address different failures and need independent coverage.

Simplifying controls should remove duplicated semantics, not hide a preferred
entry point. Keep the final user choice explicit in the decision record:
one visible search field with one shared result/matching contract. Intermediate
experiments are historical evidence, not current design guidance.

# Treat delivery stages as separate claims

A source commit, release artifact, marketplace pin and globally installed
package are different states. Verify each before advancing. Native acceptance
of the exact artifact is stronger than substituting a synthetic SDK test,
although both have value. Never use real Atlas data or privileged monitoring
merely to make synthetic demonstrations appear realistic.

When a scoped update fails because of an unrelated pin, do not repair the
unrelated package or force a broad update. An exact-ref alternative may work;
if its dry run omits cleanup/ownership effects, rehearse privately with isolated
paths and compare unrelated state before the authorized live operation.
This is a conditional method, not a promise that every APM version supports
the same safe isolation or preserves the same metadata.

Record blockers honestly, keep global installation behind marketplace
publication, and remove polling automation after the chain completes.
